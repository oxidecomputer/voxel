# Vendored browser asset

`echarts-5.5.1.min.js` is the Apache ECharts 5.5.1 browser distribution,
vendored for future self-contained, offline perftest reports. It matches the
distribution used by Charming 0.6.0. The source release is available at
<https://github.com/apache/echarts/releases/tag/5.5.1>.
